# 上下文洞察

读取 Codex 自己写下的会话元数据，生成一张离线 HTML 报告。只读元数据，不读对话正文，不联网。

## 什么时候用

- 用户问 token 用量、成本、上下文占用率、模型分布、工具调用统计
- 用户觉得上下文变慢、担心窗口快满、想确认该不该开新会话

## 怎么跑

插件根目录已由 Codex 通过 `${PLUGIN_ROOT}` 提供。生成报告：

```bash
python3 "${PLUGIN_ROOT}/scripts/report.py" --out ~/codex-context-report.html --limit 50
```

然后把路径告诉用户，让他用浏览器打开。

只要数字、不要文件时，直接看终端摘要：

```bash
python3 "${PLUGIN_ROOT}/scripts/report.py"
```

需要 JSON 做进一步分析：

```bash
python3 "${PLUGIN_ROOT}/scripts/report.py" --json /tmp/ctx.json --stdout json
```

## 参数

| 参数 | 含义 |
| --- | --- |
| `--limit N` | 纳入最近多少个会话，默认 30，`0` 表示全部 |
| `--out PATH` | HTML 输出路径 |
| `--json PATH` | 同时写 JSON |
| `--md PATH` | 同时写 Markdown |
| `--codex-home PATH` | 指定 CODEX_HOME，默认 `~/.codex` |
| `--stdout html\|json\|md\|summary` | 打印到终端的内容，默认摘要 |

## 报告里有什么

- **KPI 横条**：会话数、轮次、计费 token、成本、缓存命中率、推理 token、工具调用数、压缩次数、活跃时长
- **Token 构成（双环）**：左环是计费全貌，右环只看模型输出（可见输出 vs 推理）
- **上下文压力**：<50% / 50–70% / 70–90% / ≥90% 四档，红色意味着下次请求很可能触发自动压缩
- **上下文趋势**：逐请求的窗口占用曲线 + 窗口上限（纵轴自适应，不会压平）
- **耗时统计**：轮次总耗时拆成「模型工作」与「工具执行」；按工具耗时排行；最慢轮次
- **按日用量**：最近 14 天 token 柱状图
- **模型分布 / 工具调用 / 对话解剖**：谁在干活、调了什么、条目各多少
- **会话明细**：每个会话的模型、轮次、请求数、token、成本、峰值/窗口、压缩、当前占用

## 口径说明（回答用户时要说清）

- **token 取累计快照**：`total_token_usage` 本身是累计值，取最后一个事件而不是求和。
- **累计快照不是窗口占用**：`total_token_usage.input` 是所有请求的和；窗口占用只用每次请求的输入（`last_token_usage.input`），因为每轮重发整个窗口。混用会把占用率算成 100%。
- **上下文占用两个来源**：优先 `context_tokens`；缺失时用每轮请求输入推导。
- **耗时是 Codex 自己记的时间戳**，不是估算：轮次 = `task_started.started_at` → `task_complete.completed_at`（有 `duration_ms` 优先）；工具 = 调用行 → 同 `call_id` 的结果行；模型工作时间 = 轮次 − 工具。
- **未配对到结果的工具调用不计时**，避免算成瞬间完成。
- **成本是估算**：按公开单价算，不等于账单。模型不在价格表显示 `—`，不要编造。
- **只读元数据**：不含提示词、回答、工具参数、工具输出。这一点不要含糊带过。

## 报告做不到的事（被问到时如实说，不要编）

Codex 的 rollout 不记录这些数字：

- 系统提示词 / 工具定义 / 注入上下文的**分别占比**（只有合计输入）
- **首 token 时间（TTFB）**（只有事件完成时刻，看不到流式首包）
- **命令行文本**（只保留程序名计数）

## 数据在哪

`$CODEX_HOME/sessions/YYYY/MM/DD/rollout-*.jsonl`，一个会话一个文件，放在它**开始那天**的目录里。

## 出问题怎么办

| 现象 | 原因与处理 |
| --- | --- |
| 报告说没有会话 | 该机器还没跑过 Codex，或 `CODEX_HOME` 不是默认值；用 `--codex-home` 指过去 |
| 成本全是 `—` | 模型不在内置价格表里；这是有意为之，不要猜一个数字填上 |
| 数字比预期小 | 只纳入了最近 `--limit` 个会话，加 `--limit 0` 看全部 |
| 有「未识别行类型」提示 | Codex 加了新字段；已安全跳过，不影响统计 |
