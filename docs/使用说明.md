# Codex 上下文洞察 · 使用说明

作者：凪梦尘

## 先看这一页

这个工具把本机 Codex 会话中已有的记录整理成报告。报告是一张可以断网打开的 HTML；它**不是**实时监控，也不是账单。

| 你想做什么 | 该怎么做 |
| --- | --- |
| 安全地先看用量 | 运行默认的**统计模式**，然后在浏览器打开报告。 |
| 看消息、命令、文件或协作记录 | 运行**更详细分析**，看清范围和风险后，选择仅本次同意。 |
| 想在 Codex 桌面直接看少量数字 | 尝试实验性 MCP 统计入口；是否显示取决于桌面版本，当前尚未真机验收。 |
| 不想读取详细内容 | 不加 `--detailed`，或者在确认时选择否；自动钩子始终是统计模式。 |

## 一、生成统计报告

先打开终端，进入本工具文件夹：

```bash
python3 scripts/report.py --out ~/codex-context-report.html
```

运行完成后，双击 `codex-context-report.html`。Windows 终端中如果没有 `python3`，可以试 `python` 或 `py`；把 `~/...` 换成你自己的输出路径。

统计模式不提取提示词、回答、工具参数、工具输出或工作目录。它读取 token 数、模型名、工具名、时间和计数；报告本身仍可能暴露使用习惯，分享前请先查看。

## 二、生成更详细的报告

```bash
python3 scripts/report.py --detailed --limit 30 --out ~/codex-context-detail.html
```

1. 程序先显示**本次**读取的位置、最近多少个会话、输出位置及同名文件覆盖提示。
2. 确认窗口会说明可能读取消息、命令、工具输出、文件路径和 Agent 协作内容。只有选「是」才继续；选「否」、关闭窗口或取消就退出。
3. 没有图形窗口但终端是交互式的，会让你输入 `YES`；管道输入、后台进程或自动钩子不能代替确认。没有可用的确认方式就安全退出。
4. 用浏览器打开报告。搜索框和分类筛选可用于记录、文件、命令和协作区块；展开条目可查看已保存的内容。

**注意：详细报告可能含密码、私人对话和文件路径。** 请保存在仅自己能访问的目录，不要随意分享或上传；完成后由你决定是否删除。macOS/Linux 新报告文件设为仅文件所有者可读写；Windows 使用目标文件夹继承的权限，请自行检查。每次生成都要重新同意，授权不会保存在配置中。

想看更多或全部会话，分别使用 `--limit 100` 或 `--limit 0`。Codex 数据不在默认位置时，加入 `--codex-home "你的 Codex 数据目录"`。同名输出会被替换，输出不能放在会话记录目录中。

## 三、看懂数字

- **计费 token**：累计用量；不是当前上下文大小。成本是按内置单价粗略估算，未知模型留空，以官方账单为准。
- **上下文趋势**：最后一次有记录的请求读数或其输入量近似，不保证等于现在的实时窗口。逐请求表的差值只是相邻记录的差，并不证明变化原因。
- **耗时**：单次轮次墙钟时间和工具执行时间各自相加；不同工具可能同时运行，不能将两者相减当作模型实测耗时。首 token 仅在有字段时显示。
- **压缩**：显示已识别记录的保守下限，不同格式的标记可能描述同一次压缩。
- **详细条目**：显示日志中保存的内容，不是某次请求完整上下文；文件活动与命令列表可能缺项。编队里的消息和状态是历史记录，不能证明现在仍在运行。
- **未知**：缺记录时留空或显示 `—`，不代表真实值一定为零；跨会话历史可能含继承的重复记录。

## 四、Codex 桌面入口与安装

项目含本地 MCP 统计面板。官方规范有桌面全局入口和会话侧栏入口，但本版本尚无真实 Codex 桌面验收：如果你的版本不显示，使用上面的离线 HTML 即可。MCP 面板只给界面传递统计数字，不暴露详细内容给模型。

可以自行在安装了 Codex 的机器上注册本地 MCP：

```bash
codex mcp add context-insight -- python3 /绝对路径/codex-context/scripts/mcp_server.py
```

这会更改 Codex 的 MCP 配置，由你决定是否运行；Windows 若命令不同，请使用可用的 Python 命令。也可以用项目的 `python3 install.py` 安装本地插件：它会复制既有插件组件（包括原有技能目录）并登记本机市场。更新前先备份自己当前的插件目录和配置；`python3 install.py --dry-run` 可先查看计划。安装后按 Codex 本机版本的提示启用插件并审阅钩子；是否需要重新打开应用以加载，由你的 Codex 版本决定。本工具不会替你重启。

## 五、问题和恢复

| 现象 | 处理 |
| --- | --- |
| 没找到会话 | 确认本机使用过 Codex，并用 `--codex-home` 指向正确位置。 |
| 详细模式取消或无法授权 | 到图形桌面运行；没有 Tk 时在真实交互终端运行。不要通过管道传入确认。 |
| 某些数据是 `—` | 日志缺字段、尚未识别或不支持可靠推断；不是自动补零。 |
| 桌面没有面板 | 该入口尚未在真实 Codex 桌面验证；先用本地离线 HTML。 |
| 更新想回退 | 恢复自己更新前备份的插件文件和配置，或参考 GitHub 更新前版本；不要覆盖其他人同时作出的更改。 |

报告工具本身不联网、不上传。Codex 宿主自己的联网、日志或遥测不由此工具控制。更多技术口径与官方参考见仓库首页。
